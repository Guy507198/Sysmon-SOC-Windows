# Sysmon-SOC-Windows – Analytics Rules

Ce répertoire contient les règles analytiques créées pour la détection d'activités suspectes sur la machine Windows locale intégrée dans Azure Sentinel.

## Contenu

- **analytics-t1059-general.png** – Paramètres généraux de la règle MITRE T1059  
- **analytics-t1059-details.png** – Détails et paramètres avancés  
- **analytics-t1059-logic.png** – Requête KQL utilisée pour la détection  
- **analytics-t1059-created.png** – Confirmation de la création de la règle  
- **analytics-t1059-summary.png** – Résumé et aperçu dans Sentinel  

## Rôle du dossier
Les fichiers présents dans ce dossier permettent :
- de documenter la configuration complète de la règle MITRE T1059 (PowerShell obfusqué),
- d'illustrer la logique de détection via KQL,
- de tracer la création et la publication de la règle dans Sentinel.
